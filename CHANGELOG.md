# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.3.0](changelog/0.3.x/0.3.0.md) — 2026-10-30

Image references survive HTML conversion, schema descriptions are shorter, and a published guide connects the CERN Open Data analysis workflow.

## [0.2.1](changelog/0.2.x/0.2.1.md) — 2026-10-18

A limit or id batch past a tool's cap is served at the cap, resolved records are cached for 15 minutes, a JSON-stringified list is read as the array, HTML tables render row by row, and guide quotes and facet buckets disclose what they cut.

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-02 · ⚠️ Breaking

cern_opendata_get_records holds each response to 64,000 bytes and reads long bodies by offset, search gains physics-category, keyword and LHCb filters, and prefixed recids such as atlas-160006 work on every recid input.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — seven read-only tools and a record resource over the CERN Open Data Portal: faceted search, records with license and citation, file manifests, analysis environments, CMS good-run lists and HLT trigger paths.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
